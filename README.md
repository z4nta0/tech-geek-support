# TechGeek.support

Free, friendly tech help for everyday people, at
[techgeek.support](https://techgeek.support/): plain-spoken help articles
and a question form answered by email within 24 hours. One of three sister
sites, with [TechGeek.dev](https://techgeek.dev/) and
[TechGeek.cards](https://techgeek.cards/), sharing the
[techgeek-design](https://github.com/z4nta0/techgeek-design) package.

The site is being rebuilt; this README is rewritten when the rebuild is done.

## Scripts

- `npm run dev`: the development server.
- `npm run build`: type check and build into `dist/`.
- `npm run lint` and `npm run typecheck`: ESLint and TypeScript.
- `npm run icons`: render the favicon set from the shared mark.
- `npm test`: every Playwright suite, in Chromium, Firefox, and WebKit.
